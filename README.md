# TSK Weapons for FiveM

Türk Silahlı Kuvvetleri envanterinde bulunan silahların FiveM platformu için hazırlanmış, oyuna entegre edilmeye hazır modellerini içeren açık kaynaklı bir projedir.

##  Silah Listesi

- **MPT-76** – Piyade Tüfeği
- **SAR-109T** – Hafif Makineli Tüfek
- **KCR-556** – Piyade Tüfeği
- **Canik TP9** – Yarı Otomatik Tabanca
- **Bora-12** – Keskin Nişancı Tüfeği
